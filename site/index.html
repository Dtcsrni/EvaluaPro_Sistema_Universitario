Preguntas frecuentes

Antes de empezar

¿Qué versión debo descargar?

Abre la página de Releases y descarga el instalador docente-local de la versión publicada que quieras usar. Verifica el checksum asociado. La página de GitHub muestra la release pública más reciente.

¿La instalación funciona sin internet?

La descarga y las actualizaciones requieren conexión. El trabajo local con los datos ya instalados se realiza en el equipo; las funciones que usan Google Classroom, correo o un portal remoto requieren sus servicios y configuración.

¿Puedo usar los mismos datos en dos computadoras?

Sí, mediante un flujo explícito de exportación e importación. No sincronices directamente la base SQLite activa con OneDrive, USB o una carpeta de red. Sigue la guía de migración y conserva un respaldo.

¿OMR asigna calificaciones sin intervención?

La lectura óptica ayuda a procesar las marcas. El docente debe revisar los casos dudosos y confirmar la calificación según la política de evaluación.

¿Cómo reporto un problema o consulto la licencia?

Para un problema reproducible, abre un reporte en GitHub e incluye la versión instalada y los pasos sin adjuntar datos personales ni credenciales. Para una consulta de licencia puedes escribir a armsystechno@gmail.com.
