Para el producto que se mantiene para distribución, consulta la [página de Releases](https://github.com/Dtcsrni/EvaluaPro_Sistema_Universitario/releases/latest), el [README principal](../../README.md) y el [estado de releases](../RELEASE_STATUS.md). Antes de reutilizar cualquier propuesta de esta carpeta, confirma su vigencia, alcance técnico, precio, condiciones legales y aprobación comercial con la fuente responsable.
