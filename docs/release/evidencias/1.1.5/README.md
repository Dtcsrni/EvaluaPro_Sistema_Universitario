# Evidencia de release 1.1.5

Esta carpeta conserva la evidencia versionada de `v1.1.5`, cuyo objetivo incluye la corrección de generación masiva de exámenes y los ajustes de plantillas docentes.

La evidencia automatizada y de instalador quedó validada en el commit `157229e09e341c69a2fd897cfcc0c6096a0ebda3`. El gate estable requiere además esta carpeta para mantener la trazabilidad de la promoción.

La validación humana productiva no se ejecutó contra un servicio productivo en esta sesión; la instalación local, el backend local, el bundle docente y los contratos automatizados sí fueron comprobados.
